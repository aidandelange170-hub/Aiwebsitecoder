# Our Place AI Website Builder

A React-based application that leverages AI to help generate website code. This project includes components for code editing, AI model selection, theme switching, and a gallery for showcasing generated content.

## Features

- **AI-Powered Code Generation**: Uses multiple AI models to assist with code creation
- **Code Editor**: Built-in editor for writing and modifying code
- **Model Selection**: Choose from different AI models for code generation
- **Theme Switching**: Light and dark mode support
- **Gallery**: View and manage generated website components

## Components

- `App.js`: Main application component
- `Editor.js`: Code editor interface
- `Gallery.js`: Gallery for displaying generated content
- `ModelSelector.js`: Component for selecting different AI models
- `MultiAICoder.js`: Core logic for AI integration
- `ThemeSwitcher.js`: Theme management functionality
